💡 When to choose A* over Dijkstra?

Dijkstra expands uniformly in all directions like a water ripple. A* biases search towards the destination node using an estimated heuristic \(h(n)\). This drastically cuts explored nodes by 60–85% in geographical and spatial routing without losing optimality.

⚠️ Why Negative Edge Detection Matters?

Dijkstra fails or enters infinite loops with negative weights because it assumes adding an edge only increases path cost. Bellman-Ford correctly relaxes all edges \(V - 1\) times and flags negative cycles (crucial for finding currency exchange arbitrage loops).

🌐 Single-Source vs All-Pairs

Dijkstra/A* solve Single-Source Shortest Paths (SSSP). If a client needs distance between every airport pair or multi-stop logistics routes, Floyd-Warshall precomputes the entire \(N \times N\) matrix.
